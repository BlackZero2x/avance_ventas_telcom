# Cuadro resumen por supervisor

Carpeta de referencia para el diseño visual del cuadro resumen por
supervisor generado por `modules/cuadro_resumen_sup_process.py`.

Los datos (nombres de vendedores, RT/RU/ALTAS) se arman dinámicamente
en cada ejecución a partir de la hoja RRHH y las hojas RT/ALTAS del
archivo `AVANCE_{fecha}.xlsx` — no hay datos fijos ni de referencia
almacenados en el repositorio.

Las capturas de ejemplo generadas localmente (con nombres y cifras
reales de vendedores) no se versionan — ver `.gitignore`.
